# 按问题与数据条件选择

图的意义来自它回答的问题、观测粒度和统计口径。先检查真正影响选择的字段/单位、有效 N、分组变异和缺失；无需固定的全量画像流程。没有具体问题时选一个有数据依据的入口图，简短说明原因；无法确定关键字段含义时先澄清。

| 用户问题 | 选择与必要判断 |
| --- | --- |
| 分布、长尾、集中位置 | histogram 使用真实原始数值；0、重复、尾部保留。箱数会改变外观，不声称默认分箱最佳；不为好看加平滑、对数变换或截断 |
| 不超过阈值的比例、累计占比 | ecdfPlot；真实右连续跳点，重复值计入分母，不能把 KDE/直方图的密度高度当概率 |
| 类别人/记录数或比例 | countPlot 每行是一条观测；比例明确全表还是系列内分母。汇总 count/均值不是这种输入，不能展开假样本 |
| 各组有何差别 | 先看组内有效 N/变异；少量或常量观测用 strip/swarm 展示个体，箱线摘要需说明小样本限制。需要密度且数据足够时再考虑 violin/KDE，不用任意 N 阈值替代判断 |
| 两个数值有什么关系 | scatterPlot，按需要保留系列；纯散点不默认拟合。密集点可用 hexbin，但它不支持 series；有分组需求时保留分组散点或分图，不丢分组来迁就分箱 |
| 多个测量变量的关系 | correlationMatrix/pairPlot；选有实际意义的变量，不混数字 ID。逐对 null 处理、有效 n 和常量 NA 有意义；相关不证明因果。pair 范围/规模见协议 |
| 哪些观测字段缺失 | missingValueMatrix；JSON 仅 null 缺失，0/false/空字符串是已观测，不用一个清洗规则覆盖所有图 |
| 同一对象前后差别 | pairedComparisonPlot 需要真实 ID 和阶段顺序，不能按行序配对；连接线本身不证明干预因果 |
| 时间变化 | 使用真实时间和系列顺序；timeSeries 原始/估计模式的聚合、区间含义要明确。ACF/PACF 的输入顺序不能任意重排，二者不是普通折线变体 |
| 已有模型或区间结果 | 保留训练/验证来源、方法、正例和指标定义。UMAP 得分不用解释方差；PCA 得分/解释率/载荷是不同对象。lower/upper 含义未知时澄清，不填默认 95% CI |

单样本/常数组不能自动估计正 KDE 带宽。用户明确要求 violin/KDE 时说明实际数据限制，讨论有依据的固定带宽或替代图；不擅自用“1000 元”等示例参数使图看起来成功。仅凭原始高维数据不能生成 PCA/UMAP 得分；没有真实 SHAP/预测/重要度结果也不编造它们。

组间密度、频数和区间有不同口径：KDE 的 all/series、violin 的 area/count/width、样本百分位与置信/预测区间按选中图的短指南处理，不能凭图名推断。明确拟合请求才添加模型，并说明实际参数；不自动附显著性、p-value 或因果解释。

普通蜂群是 stripPlot 的 swarm，SHAP 蜂群有自己的输入；UMAP 是 embeddingPlot 的 method 变体，PACF 是 autocorrelationPlot 的 method 变体。特殊变体从索引的 variantFile 中读取对应 type 的 options/固定链接，不另维护别名表。

默认图数和页面交互遵循入口与协议。标题如“东区各部门收入分布”比“箱线图”更明确；单位、范围、必要的小样本/区间短注不能省略。更多图不等于更多信息，只有新增视角能回答不同问题时才增加图。
