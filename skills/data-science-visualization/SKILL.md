# 数据科学可视化

生成一张能回答用户问题的图；需要互补视角时才组合多图。默认只展示标题、图表、单位与真实 Tooltip，保留必要静态图例和色标；其他交互只来自明确需求。

## 选择有意义的图

先明确观测是什么、要比较什么、字段含义/单位和数据范围。只检查会影响选择的缺失、组内有效样本、常量或点密集程度；不自动生成审计报告。数字 ID 不因是 number 就变成测量指标，唯一性也不单独证明一个字段是 ID。

按 [问题与数据条件](references/chart-selection.md) 选择图义。用户指定图型时，在数据含义和输入契约成立的前提下尊重选择。想画某种图不等于确认其统计口径：当上下界含义未知时，先询问它们代表置信区间、预测区间、分位区间还是范围；确认前不生成带该统计定义的请求。不能通过添加“含义未知”图注，将未知上下界填成 confidence/0.95。用户或输入元数据已明确给出区间定义和水平时直接使用，不重复询问。其他数据条件不满足契约时说明原因，不静默换图、猜带宽或伪造结果。

定位[本地索引](references/statplots/index.json)中选中 type 的条目，读取其本地 guide、typeFile 及必要 import 依赖、example 最小输入。索引每行一图，可按 type 定位；不要读完整联合声明或全部指南。特殊变体才读取 variantFile 中对应 type 的 options 和选中条目的本地 example，路径相对 references/statplots 根目录；不要预读全部变体示例。公共数值、区间或配色条件见 [公共约束](references/statplots/guides/common.md)。TS 是字段参考，最终仍由公共 validate/compile 校验。

## 生成与交付

复用生成器，不重写 HTML 或绘图计算。[输入与交互协议](references/input-and-interaction.md) 维护表格绑定、直接 Spec、预算和按需控件。`examples/` 为六份可执行演示；基础例子无控件，interactive.json 仅供明确交互需求参考，演示数据不能当用户数据。

```sh
python3 /实际技能目录/scripts/generate_visualization.py \
  --request /实际请求目录/request.json \
  --output /新的输出目录
```

Python 3.11+，CSV/TSV/JSON 只需标准库；XLSX 可选 openpyxl 并明确 sheet。首次配置、Windows 调用或依赖／宿主失败时读取[运行环境与交付](references/runtime-environment.md)，使用同一解释器检查依赖和生成。输出 HTML、可重放 request 和带来源的 data；输出目录必须不存在。HTML 内嵌使用数据，VChart/statplots 使用 [release.json](release.json) 指定的同版本固定 CDN；打开需网络及外部脚本权限，无需 npm、TypeScript、MCP 或本地服务器。

标题写实际变量、比较对象和必要范围，轴/Tooltip 保留单位。不把相关当因果，不添加分析面板。不展开聚合频数、不默认采样/截断、不猜区间或降维坐标；原始模型计算和完整推断报告使用分析工作流。

每版结果交付三个具体文件链接：visualization.html（交互图）、visualization.request.json（继续改图与重放）、visualization.data.json（使用数据及来源）。使用宿主支持的文件卡片或附件，确认三份文件均可访问；文件夹卡片、正文中的磁盘路径及“已保存”不能代替文件交付。说明影响解读的数据范围、缺失省略或小样本限制。文件交付受阻时逐项说明已完成和未完成部分，不声称完整交付。

## 验收与继续改图

交付前，在宿主支持的浏览器或交互预览中实际打开 HTML，检查图元、至少一个有代表性的真实 Tooltip 以及用户请求的交互；静态缩略图、文件存在或 canvas 存在不能代替验证。宿主不要求截图不等于交互已经验证；无需为自检增加用户未请求的页面功能。工具或宿主规则不允许检查时，记录未验证环节，不绕过限制，不声称已验证。`window.__DSV_STATUS__.ready` 只表示批次结束，成功需每图 status=rendered；输入/省略数及详细错误保留在状态对象。

文字中的分箱数量、区间频数、样本数和统计结论必须依据实际生成结果核对，不能从输入行数或不同值个数推测；没有核实的精确结论不写。无需为了自检额外撰写统计分析报告。

对话改图读取磁盘 visualization.request.json，保留全部使用行、ID、单位、固定条件和按需选项，修改请求后生成新目录。新增未内嵌字段时从已知原数据按真实 ID 补回；request 不是全列备份。浏览器后续选择不自动写回磁盘，不可读取时确认具体条件；用户请求保存当前视图时才提供 saveView。

请整体使用版本匹配的技能包。参考资源缺失或版本不一致时停止生成，更新完整技能包后再运行，不单独修改库版本。
