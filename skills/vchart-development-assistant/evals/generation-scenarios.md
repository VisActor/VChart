# 生成场景前向测试

使用仓库技能及下列真实请求，在独立上下文执行；按需读取技能引用，不提供预期答案、优化计划或其他任务产物。临时输出放在仓库之外，保留实际配置、页面、截图和验证记录。不建设模型调用框架，不把手工示例测试计入 Agent 行为通过。

同一批任务使用相同继承模型/推理设置，不做模型覆盖。工具未提供确切模型标识时记录这一限制。G01–G04 各运行三次，其余至少一次；G08 两个子任务分开。重复只作为冒烟检查，不推导长期成功率。

## 证据与执行

每份任务记录独立 Agent 任务标识、是否澄清、读取的流程、产物路径，以及实际完成的格式/数据/渲染/交互检查。需读取对应 Agent 的实际工具过程或产物，不凭其最终自述判全部通过。

JSON 解析不代表配置有效；HTML 存在不代表图表已经绘制。浏览器检查图元数据、字段、标签及要求的交互；无法渲染或无法访问目标宿主时分别记录未执行。

G01–G04 的旧版与新版对比使用相同原始请求、相同模型设置和独立技能副本；旧版只从仓库 HEAD 取技能资源，不能覆盖当前工作区。结果只描述观察到的差异，不预设旧版必失败或据少数任务推导成功率。

执行结果与复现材料在本次 validation 文档中登记；此文件定义任务，不预填通过。
