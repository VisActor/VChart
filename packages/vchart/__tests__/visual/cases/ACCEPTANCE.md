# 视觉测试验收摘要

截至 2026-09-23，256 个本地用例的 macOS 与 Linux 验收通过。Linux 实测 veLinux 2 x64；Ubuntu 未独立实测，不作为本轮交付阻塞项。该结论不宣称所有发行版、浏览器或全部 VChart 功能均已覆盖。

## 实测环境与结果

两平台均使用 Node 22.22.2、Playwright 1.63.0、Chromium 153.0.8010.12；单 worker、无自动重试、DPR 1、en-US、UTC，颜色阈值 0.1、允许差异像素数 0。同机比较两侧，不要求跨平台像素一致。

| 环境                                            | 结果                                                                                                   |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| macOS arm64                                     | 五轮 256/256 自比较、官方 develop 256/256、固定 SHA 单例和 api/update 目录通过                         |
| veLinux 2 x64（Debian bookworm 系、glibc 2.36） | 五轮 256/256 自比较、官方 develop 独立安装/构建后 256/256、固定 SHA 缓存命中单例和 api/update 目录通过 |

每个平台的五轮稳定性均为首轮正式 CLI 构建，后四轮复用同一产物并重新生成两侧截图，并非五次重新构建。Linux 上 Playwright 使用 ubuntu24.04-x64 浏览器构建；Arial 回退到 Liberation Sans，中文字体为 Noto Sans CJK SC。

两平台均完成 32 项工具检查；15 项静态目标配置变异检出差异，15 项匹配流程对照通过；50 项动作抑制返回执行错误，50 项正常交互基线通过，50 项候选动作省略的截图反例检出差异。反例只运行在独立验证副本中，正式执行不跳过断言；这些结果不是全部 spec 分支的变异覆盖率。

同时验证了候选颜色/位置/标签差异、空图、资源与渲染失败、超时、缺图、结果集合、报告及清理失败、离线和搬迁后报告。未提交源码进入本地构建，fork origin 不改变官方基线，损坏缓存重建，锁冲突不影响原任务，构建/截图/基线安装期间中断均留下错误诊断并清理本次资源。Linux 证据取回后已清理远端测试内容。

Linux 验收期间修复 Git 自动延长对象缩写导致的工作区摘要误报，改用 `git diff --binary --full-index`。五轮稳定性在该修复前完成；修复不改变构建配方、用例或渲染。修复后重新通过 Linux 完整工具检查、官方全量、单例、目录、未提交源码、缓存及中断验证，macOS 相关回归检查 8/8 通过。
