## 来源审核和边界

外部模型对 65 个最终候选给出 56 项“保真”、9 项“需修改”。模型意见不代替源码和运行证据，九项分别处理如下：

| 用例                     | 最终处理                                                                               |
| ------------------------ | -------------------------------------------------------------------------------------- |
| data-fields-domain       | 从源数据及 domain 计算过滤后的有序结果和图元数量，保留重复点，不硬编码计数或推断轴下界 |
| datazoom-preview         | 明示 width=400 的宿主适配，保留 auto/minBandSize 和数据，断言 dataZoom 实际显示        |
| pie-show-all-zero        | 检查三个非退化环形扇区及标签；不声称已测试 select/indicator 交互                       |
| sunburst-gap             | 源构造器明确禁用动画，保持最终静态截图约定，不采纳必须打开动画的意见                   |
| treemap-hierarchy        | 补充标题与标签实际绘制检查，收窄覆盖说明                                               |
| update-indicator-visible | 检查最初隐藏、更新后显示；从同一冻结模块构造更新 spec                                  |
| brush-select             | 保留矩形拖拽，按实际图元适配坐标并检查命中/未命中状态；不迁移另一个空白点击复位子例    |
| legend-continuous-filter | 按手柄实际方向拖拽，检查范围及数据过滤；不要求复刻旧宿主像素坐标                       |
| correlation-tooltip      | 匿名化公开源词条，保留数值和顺序；悬停首个实际节点，不宣称其是历史录制坐标的原目标     |

原始源码、模型请求/响应及逐项去向保存在内部准备记录，不能提交公开仓库。业务目录未迁移；公开用例不含内网地址、服务密钥、外部图片或远程字体。尚未选中的来源不等于已逐一判定低质量。后续独立新增场景应走新的用例准备流程。
