# PCA/SHAP 空画布排查及密集 SHAP 验证

## 判断

本次未复现上一轮的空画布捕获帧，**不能唯一确认为截图工具或图表重绘故障**。已测试的图表路径正常，暂无证据支持修改 VChart、VRender 或 Skill 的重绘路径。宿主截图过程确实出现 DPR 2→1→2 的切换，但这不是旧空帧成因的充分证据。

## 对照证据

- 原始 PCA 和稀疏 SHAP 的 HTML 保留原字节，PCA 重新生成的 HTML 也与原文件逐字节一致；库固定为 VChart/statplots 2.2.2，发布 UMD 缓存重新核对 SHA-256。
- 独立 Chromium：2 种图、DPR 1/2、1100→319→1100 宽度、初始/真实悬停/指针移出、每阶段 3 次截图，共 108 组画布像素与截图像素对照，无空白、无页面错误。
- CUA：保留的 24 张连续截图均检查实际绘图区彩色像素，无空白。只读诊断副本直接读取 canvas 的真实缓冲区、尺寸、图元和渲染状态；PCA 30 图元及 SHAP 36 图元、非空像素均正常。
- 诊断分别使用逐帧只读观测和仅按需读取的副本；后者避免持续像素读取或诊断 DOM 更新掩盖截图问题。没有调用额外 render/resize/update 作为修复。
- 单独复查宿主原生截图、fullPage 截图、viewport 重置及宽度切换；读到 DPR 变化，未获得“失败截图与同一时刻 canvas 像素”的失配证据。因此不把“未发现重绘故障”写成“已经证明截图工具有 bug”。

## 密集 SHAP

- 固定输入从 12 个样本/36 条记录扩为 240 个样本/720 条记录，原 36 条检查点逐项保留。新增值来自等间隔概率点的正态分位数与确定性公式，贡献量化到 0.025 log-odds；由原生蜂群布局排布，不手工改图元坐标。
- 三个特征各 240 个真实图元，DPR 1/2 下分别有 156、167、178 个不同 y 位置，堆叠高度约 51.43、57.07、60.26 CSS px。
- 两种 DPR 各 9 次真实无点击悬停均核对样本 ID 与特征，覆盖原 S012 正/负贡献、S004 零贡献/缺失值和每行堆叠上、下缘。另在 CUA 中点击定位 S087、S127、S012、S004，读到与输入一致的 Tooltip。
- 仍保留 8 条特征值缺失、有效 SHAP 的记录。1100 宽度下库报告拥挤点 1+0+4=5 个；未丢弃、采样或隐藏警告。密集数据在窄屏下更拥挤，本次不承诺所有点在所有尺寸下均能单独命中。
- 新 SHAP 在 DPR 1/2、1100→319→1100 下共 30 次画布/截图检查无空白，生成与独立重放通过；8 例共 16 个输入清单/哈希、字段、复合 ID、原始检查点和 Markdown 链接通过。
