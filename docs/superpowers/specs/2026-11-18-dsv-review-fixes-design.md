# 数据科学可视化 PR #4742 修复设计

用户已在 review 核查后确认修复两项问题。

## 固定筛选与预算

生成器按 `field + kind` 区分固定初始条件与可编辑条件。只有没有对应筛选控件的初始条件参与预算预过滤，类别和闭区间语义与 `StatPlotData.filterRows` 一致。保留完整 payload 数据和来源计数；可清空的条件不能用于绕过预算。

## 页面事务回滚

控制器负责单图更新的原子性：编译失败保留原图，原生更新失败尝试恢复旧图。页面只回滚本轮成功更新的图；失败图仅在控制器仍存在但已无图时参与恢复。恢复失败继续显示真实失败状态，不通过重复绘制掩盖。

## 验收

- KDE、violin 在 21 组数据固定为 1 组时可生成；条件可编辑或固定条件仍超过 20 组时拒绝。
- 覆盖固定类别、闭区间、无界端点、null，以及完整数据保留。
- KDE 编译拒绝不调用失败图的原生更新；之前已更新的图回到旧 spec 和真实图元。
- 原生失败后内部恢复成功不触发页面重复更新；真实恢复失败保留错误，后续正常操作可恢复。
- Python、运行时、浏览器相关测试与仓库视觉基线比较如实记录结果。
