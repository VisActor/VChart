# 数据科学可视化技能：精简资源与有意义的选图

日期：2026-10-12；分支：`codex/vchart-statplots`；基于 `83eb8f7ce`。本轮交付设计和实施计划，不修改技能行为。

## 目标与问题

用户希望技能内容更简洁，能从真实数据生成有意义的数据科学图表。目标包含两件事：模型只读取决策所需资源；选出的图能回答问题、表达真实数据口径。仅把 Schema 换成 TS，不能单独保证第二件事。

当前技能已具备固定发布版本、12 类表格绑定、28 类规范 Spec、简洁默认页、公共校验/编译和可重放产物。这些能力继续保留。

本地资源审计：docs 33 文件/133256 字节；examples 80 文件/185748 字节；Schema 28 文件/148554 字节。文档中八段 JSON 与独立最小示例完全相同；示例文件之间没有完全重复。Schema 在 skill 中只供阅读，HTML 运行时调用固定 UMD 的 validateStatPlot，不读取这些 Schema 文件。同步脚本直接复制文档、Schema 和全部目录变体，导致模型参考和运行验证的职责混在一起。

## 方案选择

1. **推荐：同版本 TS 声明 + 精简统计语义 + 唯一最小示例。** 从核验的 npm 发布物生成技能资源，保留来源与同步检查；校验仍交给公共 UMD。
2. TS/Schema/完整文档全部保留，仅调整阅读顺序。改动较少，但重复资源仍存在，后续引用容易重新引入大上下文。
3. 只保留简短人工说明，其他资源全部在线读取。目录最小，但首次生成依赖额外网络，类型和语义容易偏离固定版本。

采用第一种。保持固定版本 2.1.8-alpha.0；无需先发布新包，不从当前分支源码冒充该发布版本的声明。

## 资源的单一职责

| 资源 | 职责与来源 |
| --- | --- |
| `SKILL.md` | 目的、必要决策、生成/验收/改图入口；不重复列举全部类型和参数 |
| `references/chart-selection.md` | 按问题与数据条件选图，保留改变选择的边界 |
| `references/input-and-interaction.md` | 技能 request/表格绑定/按需交互协议；只维护 skill 自己增加的契约 |
| `references/statplots/index.json` | 28 类 type、名称、用途/不适用条件、类型文件、短指南、唯一最小例子；变体保留选项与固定发布链接 |
| `references/statplots/types/` | 从发布物 `esm/types.d.ts` 开始的 Spec 声明依赖闭包，保持相对路径与原字节 |
| `references/statplots/guides/<type>.md` | 从同版本逐图文档提取输入语义、默认值、统计口径和必要边界；链接类型及示例，不重复 JSON |
| `references/statplots/examples/specs/minimal/` | 每类一个发布物中的可执行最小 Spec，共 28 份 |
| manifest/许可证/包元数据 | npm 完整性、原文件和生成文件哈希、转换规则版本、共享控制器来源 |

技能目录不再同步 JSON Schema、完整逐图手册、全图参数汇总 spec.md、上游通用 skill-authoring.md 和 computation-contract.md。当前 80 份示例只保留 28 份最小输入。Schema/校验器仍在 statplots 包中正常维护；变体和完整手册需要时通过固定版本链接读取，不能使用 latest。

原 README.md 的包使用手册不再复制；package.json、LICENSE、THIRD_PARTY_LICENSES.md 和 manifest 保留用于来源与许可。总正文指标统计 index/types/guides/examples，基线对应旧 catalog/Schema/docs/examples；来源/许可元数据单列统计，前后采用同一规则。

`types/types.d.ts` 只作为 Spec 声明入口，不复制 API 实现声明及整个 VChart 类型树，不模拟一个可安装 npm SDK。默认读取选中图的声明及其直接依赖；索引和联合入口用于定位/维护，不能要求每次读完 28 类。

发布 `.d.ts` 可能没有 JSDoc，且 number 类型不能表达有限数、整数范围、series 一致性或统计假设。因此指南必须保留这些含义，不能用“已有 TS”作为删除依据。

## 同步与维护

- 核验固定 npm tarball dist.integrity，读取发布声明与逐图文档。类型闭包通过 TypeScript AST 遍历相对 import/export；路径逃逸、缺失声明、意外外部类型依赖均明确失败，不复制编译实现来补齐。
- 从声明的 StatPlotSpec 联合解析具名类型与 type 判别值，生成 28 类的类型映射；无需手工维护另一份联合类型。
- 引入仓库维护配置 `visualization-skill-resources.json`：仅记录每类文档需要保留的章节选择器，不手写参数或第二套统计说明。来源文档章节不存在时同步失败，版本升级由维护者审阅选择器。
- 指南保留来源正文，删除 JSON 示例块、迁移历史、测试/构建命令、图库和性能实现描述、Python 库逐项对比；不删除默认值、分母、缺失口径、样本/区间模式和小样本限制。更新链接到同一索引的类型和最小例子。
- 共享颜色/区间/缺失的一般约束只在一份 `guides/common.md` 维护，取自同版本源文档；各图只保留自身差异。不为每类复制 BaseSpec 字段说明。
- manifest 区分直接发布副本与生成指南/索引，记录 source/sourceSha256/sha256、转换规则与选择器哈希。导入闭包、链接和文件清单在 --check 中核验，不能只有“文件 hash 相同”就认定引用有效。
- 整套资源在 staging 中完成后替换；失败保留上次完整资源和共享 controller 副本。同步删除旧目录，防止下一轮又积累 Schema/变体/手册。controller 继续沿用现有源和同步机制，渲染路径不变。

## 有意义的选图

入口围绕“问题 → 实际字段与数据条件 → 图义 → 必要选项 → 真实验收”。检查只做会改变选择的部分，不生成固定格式的数据审计报告，不新增通用统计框架或科学计算环境。

- 明确观测粒度、比较对象、指标/单位与范围。数字编码和 ID 不能因为是 number 就默认作为相关性指标；唯一性也不能单独证明一个字段是 ID。
- 分布问题看真实样本；阈值/累计占比优先 ECDF；分组比较先检查各组有效 N 和变异。小到摘要会掩盖个体时优先展示 strip/swarm；单样本/常数组不能自动估计 KDE 带宽，不为“好看”随意填固定带宽。
- 对已经明确指定图型的请求，保留用户选择；无法满足契约时解释数据条件并讨论实际带宽或替代图，不静默换图。
- 关系图选择有业务/测量含义的变量；只有需要互补视角才组合散点、相关或 pair。相关不代表因果。密集散点可以选择 hexbin，但分组语义不能丢失，hexbin 不支持 series。
- 频数、均值、概率密度和累计概率不能互相替代；各组比例的分母、缺失排除和固定范围必须明确。缺失检查保留 null/0/false 差异。
- 聚合表不能展开为假样本；已有模型结果保留真实方法/来源，未知区间不猜 95% confidence；只有高维原数据时不编造 PCA/UMAP 得分。
- 标题写实际变量、比较对象和必要范围，例如“东区各部门收入分布”；轴和 Tooltip 保留单位。只有必要的小样本/区间图义使用短图注，默认不增加分析面板。

没有具体问题时，依据字段含义和数据条件选择一个有依据的入口图，并简短说明原因；关键含义无法确定时只澄清影响图义的问题。首版不新增自动全量分析、检验、模型训练、数据采样或通用 profiler。

## 阅读与改图流程

普通需求读 SKILL 及必要的选图条目，定位 selected type 后读取短指南、对应 `.d.ts` 及必要依赖、唯一最小 JSON。只有特殊变体/数值边界才读取固定版本的完整手册。

删除 SKILL 与 chart-selection 的重复图名清单和重复控件说明；详细 request/预算/交互口径只放协议。生成器仍接受 JSON，浏览器仍使用 validate/compile；不要求用户安装 TypeScript。

改图继续读取 request，保留完整使用行、ID、单位、固定范围与按需选项。新增此前未内嵌的字段时回到已知原数据按真实 ID 补回，不能把回放请求当全列数据备份。用户只要求改图型时不添加编辑控件。

## 验收

结构验收包括 28 类声明完整、类型相对引用无缺失、指南链接有效、最小例子唯一、无 Schema 残留、离线检查与失败同步保留原资源。开发端可用 tsc 检查声明，技能使用端不依赖编译器。

精简效果使用实际字节和真实读取文件列表衡量，不把文件数当质量、不把字节数称为模型 token。目标：整个 statplots reference 正文总字节较本轮基线减少至少 40%；histogram/box/violin/correlation/pair 五种常见需求的平均首次必读资源字节减少至少 30%。不为达标删除必要统计含义；不足时先重新审查同步范围。

行为验收使用真实请求和原始数据，检查输入角色、范围、N/分母、图元/Tooltip、默认控件、对话重放与解释限制。覆盖普通分布、阈值、小样本组比较、密集关系、相关/pair 缺失、已有降维、改图，以及聚合频数/未知区间/原始高维/单样本小提琴的边界。允许多个合理图型，以能否回答问题和保持口径评估，不固定关键词命中或唯一图名。

固定发布 28 类渲染与 12 类绑定、六份便携输出、原有最小页面与交互回归继续运行。此前 447/664 结果不代表本轮；官方基线与扩展 tsc 既有阻断若仍存在，分别如实记录。仅参考目录与文档更新不要求更改核心视觉测试基础设施。

## 实施补充（2026-10-13）

实测把变体全部内联在 index 中，五图平均首次必读字节只下降 20.5%，未达到本设计的 30%。最终将变体元数据放到独立 variants.json，index 用 variantFile 按需指向。两者仍计入全部正文，变体能力/固定链接继续保留；正文下降 70.5%，五图平均首读下降 52.2%。类型、统计语义与最小例子未因此删减。实际行为和回归证据见 [资源验收](../validation/2026-10-12-data-science-visualization-resources.md)。
