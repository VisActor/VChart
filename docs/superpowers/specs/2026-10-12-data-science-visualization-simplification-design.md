# 数据科学可视化页面简化设计

日期：2026-10-12；分支：`codex/vchart-statplots`；基于 `01d84fe64`。

## 目标与根因

用户已明确：默认只展示图表、标题、单位和 Tooltip；其他交互按需求添加；改图通过对话完成。本设计与计划属于本轮规划交付，实施另行执行。

当前复杂度来自页面模板把通用探索工具当成默认交付：无控件声明时仍生成操作栏、应用/清空、主题、配置下载、保存视图、PNG、成功计数、来源哈希、数据说明和技术页脚。HTML 卡片标题与 statplots 原生标题还重复。仅调整 SKILL.md 或折叠操作栏不能修复这个默认行为。

## 路径选择

1. **按需求生成页面元素，推荐。** 无声明时只有图；声明筛选时只有筛选；声明导出时才有导出。复用已有能力，默认认知成本最低。
2. 全部删除探索能力。实现略少，但用户要求筛选时需要重新开发，浪费已验证的数据与更新路径。
3. 默认折叠高级面板。修改较小，但仍保留通用工具入口，不能满足用户明确的默认画面。

采用第一种，不引入“简洁/专业/高级”模式选择器或通用设置面板。

## 默认画面

- 单图：一个 HTML 标题、图表、轴标签/单位、真实 Tooltip。无单图卡片标题、画布重复标题或原生 description 重复展示。
- 多图：页面标题一次，各图 HTML 标题一次；原生画布不重复标题。只有确实需要互补视角才生成多图。
- 坐标轴、必要的类别图例与连续色标属于图表表达，保留；默认图例只说明颜色，默认不启用图例筛选和 pair 框选。Tooltip 保留公共 API 的原生行为。
- 标量轴继续使用现有 label/unit 映射。矩阵不改实际变量键；有单位却无原生单位展示位置时，提供紧邻图表的简短单位行，不能删除现有元信息后把单位也删掉。
- 默认不显示工具栏、按钮、原始/输入条数、成功比例、来源哈希、技术标签、数据说明折叠块、技术页脚或自动提示语。未请求的元素不创建 DOM；不保留禁用按钮或空工具栏占位。
- 用户明确提供的 caption/统计区间语义保留为必要图注，不自动插入通用说明。数据省略和来源仍完整记录于 data 文件及状态对象；会改变解读的数据限制在对话交付中说明，不能因页面简化而省略事实。
- 加载中、空数据与失败是必要状态，出现时显示简短说明；成功后不残留加载/失败文案。原始详细错误保留在状态对象，页面不自动展开技术诊断。

## 按需能力与协议

保留请求 version=1；新增可选 `presentation`，缺省为空，所有增强默认关闭：

```json
{
  "presentation": {
    "actions": ["theme", "exportPNG", "exportSpec", "saveView"],
    "details": ["counts", "provenance"]
  }
}
```

actions/details 必须为唯一合法枚举数组，未知值拒绝。它们只负责页面展示，不更改统计语义。主题由图的 theme 指定时直接初绘该主题；切换按钮需明确请求。

原有 controls.filters/variableSwitch/parameters 仅在用户明确请求该页面交互时声明。只有 filters 非空才创建应用/清空按钮；只有变量/参数不创建筛选按钮；没有任何声明时不创建 toolbar。启用筛选时可显示与筛选直接相关的简短“当前 N 条”；默认不显示“成功 X/Y”。完整原始/每图输入/省略数由 counts 请求或 data/status 获取。

每个 Chart 新增可选 `interactions: ["brush", "legendFilter"]`，默认空数组。brush 第一版仅允许 pairPlot；legendFilter 不对 pairPlot 开放，也不把不存在或不具备筛选语义的图例改造成过滤器。公共 Schema 验证与对应图文档仍决定有效图义。

对话要求“仅看东区”属于固定条件，无需增加页面地区选择器。允许 controls.initialFilters 独立于 controls.filters：两者分别表示初始数据条件与用户可操作控件。初始条件按 dataset 中的声明列、kind、value、类型和存在性严格校验；只有用户请求页面调整时才声明 filters。全部观测行仍内嵌，改条件不依赖筛选子集。

未声明对应页面控件的条件属于固定范围；应用/清空其他控件时保留它，仅通过后续对话修改 request 才移除。声明了对应控件的初始条件可由该控件修改或清空。固定范围写入标题或明确图注，例如“东区收入分布”，不能让受限范围看起来代表全表。

旧请求仍可输入：已有控件声明继续生效，未声明的通用按钮不再自动生成；已经生成的旧 HTML 文件不改写。不增加恢复旧复杂页面的兼容模式。

## 复用与边界

统计、几何、Tooltip 仍由固定 `2.1.8-alpha.0` statplots/VChart 公共 API 提供。data-bindings 的统计映射、稳定 ID、预算、null 规则保持单一路径。

共享控制器增加可选 `showTitle`、`interactions`：未传时保留图库现状；技能显式传 showTitle=false 和声明的交互数组。标题/description 只从本次 compile 的浅拷贝输入中去除，以免 pair/seasonal 布局仍给隐藏标题留下空间；controller.spec、输入配置及导出 Spec 保留完整原语义。校验原 Spec，compile 一次，不修改原输入。

交互显示策略只使用标准 VChart Spec：未请求 brush 时 compiled.brush.visible=false；未请求 legendFilter 时已有 legend.interactive=false。请求交互时保留该图原生配置，不强行开启上游已明确禁用的交互。没有组件时不创建组件。支持单个/数组形态的标准组件，不依赖私有图元结构。

修改共享控制器源后经现有 sync 脚本生成技能副本、更新哈希，不手改副本，不为技能另写 renderer；图库继续保持既有行为与布局。npm 契约快照、版本、依赖及 statplots 数学实现均不纳入本次改动。

## 对话改图

生成器继续交付 HTML/request/data 三项文件。默认从磁盘 visualization.request.json 修改图型、字段、单位、条件或主题，输出新目录；页面不承担默认编辑器职责。

已有 request 的 initialFilters、原始使用行、ID、单位和 presentation 均保留。若用户只说“改为小提琴”，不增加任何按钮或参数控件。浏览器里后来改变的条件不会自动写回磁盘；无法读取该状态时向用户确认具体条件，不假装已获取，也不要求每次先点击保存。只有用户明确请求保存当前浏览器视图时才启用 saveView，沿用已有下载与重放实现。

## 验收要求

1. 最小请求实际生成并渲染：无 toolbar/按钮/select/input/技术说明；一次标题，单位和鼠标 Tooltip 正确。
2. 逐项开启只出现对应能力；过滤后的真实计数/相关与分母正确；配置、PNG、saveView 与画面一致；默认图例点击与 pair 拖动不改变数据/选择状态，明确开启后改变真实状态。
3. 有 title/description 的 pairPlot 与 seasonalPlot 不留多余标题空白、不破坏布局；全部 28 类发布 UMD、12 类绑定保持可用。
4. 默认/筛选/多图在 360/420/1000/1440 px 验证布局、Tooltip 与必要单位；保留截图并审阅。
5. 对话固定条件无筛选控件，改图后仍保持条件及全部使用行；旧 request 兼容、原生错误恢复、资源同步、图库回归和 10k 实例复用通过。
6. 每项测试写实际结果；上一轮 427/664 成功不能作为本轮证明。扩展 tsc 与官方视觉基线的既有阻断若仍发生，保留原始错误，不跳例/放宽阈值或宣称通过。
