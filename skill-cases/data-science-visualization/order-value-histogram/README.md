# order-value-histogram

## 典型图型与场景

- 图型：`histogram`，订单金额的右偏分布。
- 覆盖：原始连续数值分箱、缺失省略、零值与重复值保留、明确请求的分箱控件。

## 数据验收

- 输入 32 行，金额有效 30 行、缺失 2 行；有效范围 0–2000 元，0 元有两笔，2000 元只有一笔。
- 初始 5 箱的边界为 0、400、800、1200、1600、2000；逐箱计数应为 25、2、1、1、1，总和 30。内部边界值归右箱，最后一箱包含最大值。
- 图形是连续金额分箱，不应变成按订单 ID 分类的柱状图；缺失不能填零，不能去重。

## 实际操作验收

1. 悬停第一箱和最后一箱，核对金额区间与订单数。
2. 将 5 箱切到 10 箱，确认实际边界/柱形改变、计数总和仍为 30；再切到 20 箱并恢复 5 箱。
3. 页面切换不自动修改磁盘 request；重放磁盘文件仍从 5 箱开始。
