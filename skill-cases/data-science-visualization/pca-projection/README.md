# pca-projection

## 典型图型与场景

- 图型：`embeddingPlot`，已有 PCA 坐标的二维投影。
- 覆盖：模型输出可视化、得分/载荷区分、解释方差元数据与分组 ID。

## 数据验收

- 30 个样本、三批各 10 个，坐标、批次与 ID 必须完整保留，不能重新训练或重排对应关系。
- method=pca；dimensions.x/y 的解释方差分别为 0.62/0.23，两轴合计 85%，不能写成解释全部方差或 62/23 的比例值。
- P001=(-2.5,0.5)，P011=(-0.5,-1.0)，P021=(1.5,0.0)；核对为主成分得分，没有温度或金额等物理单位。
- 批次是输入标签，不能把视觉分离解释为真实聚类、模型质量或因果证据。图中不能出现特征载荷箭头或伪造解释方差。

## 实际操作验收

1. 分别悬停 P001、P011、P021，核对 ID、坐标和所属批次。
2. 检查轴能读出主成分名称及 62%/23%，静态图例覆盖三批。
3. 不应出现默认过滤、框选、特征重要性图或重新计算 PCA 的流程。

## 执行与公共验收

按[执行说明](../README.md#执行方式)只复制 [prompt.md](prompt.md) 和 [inputs/](inputs/) 给 Agent；本文件及 [fixtures.json](fixtures.json) 留在验收端。输入来源与 SHA-256 见校验清单。

同时检查[公共验收标准](../README.md#公共验收标准)。允许不同的配色和布局，不要求页面或像素一致。数据事实用于检查产物，不强制把所有计算写在页面上。

本目录提供固定任务定义，不代表已经完成 Agent 执行或人工视觉验收。
