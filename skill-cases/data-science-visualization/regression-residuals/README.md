# regression-residuals

## 典型图型与场景

- 图型：`residualPlot`，已有验证集预测的误差诊断。
- 覆盖：`input=predictions`、误差符号、预测横轴与来源保留。

## 数据验收

- 20 个样本全部保留；预测范围 10–48 kWh，原始残差范围 -9–9 kWh，残差均值为 0。
- V001：actual=19、fittedValue=10、residual=+9；V010：19、28、-9；V020：57、48、+9。
- 必须使用外部预测模式并计算 actual−fittedValue；不应把已有预测作为训练标签重新拟合、翻转误差符号或改为标准化值。
- 残差随预测值呈两端正、中间负的结构；均值为零不等于没有系统结构，不强制附加模型改进结论。

## 实际操作验收

1. 悬停 V001、V010、V020，核对预测值、残差、ID 和单位。
2. 确认 y=0 线可见，横轴是预测值而非样本序号。
3. 检查 request 没有 regression、smooth 或标准化残差配置。
