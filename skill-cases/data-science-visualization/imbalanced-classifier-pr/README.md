# imbalanced-classifier-pr

## 典型图型与场景

- 图型：`precisionRecallCurve`，不平衡二分类的排序评估。
- 覆盖：正例定义、并列分数、AP、基线与真实图例过滤。

## 数据验收

- 同一批 40 个样本，每模型 4 个正例，正例率 0.1；转换为系列后每模型 N 仍为 40，不能把 80 条系列行当作单模型分母。
- 两条曲线都从无阈值的 (recall=0, precision=1) 起步；阈值降至最低时 recall=1、precision=0.1；正例率基线均为 0.1。
- 模型 A 的阈值 0.9 合并一正一负，precision=0.5、recall=0.25；阈值 0.8 时 precision=2/3、recall=0.5。
- 模型 A 的 AP=(1/2+2/3+3/5+4/7)/4≈0.5845238095。按库定义的召回增量加权精确率核对，不能用梯形积分、ROC AUC 或随意插值代替。
- Spec 输入为 actual/score/series 的原始行，不硬编码 recall/precision/AP。模型 B 也使用相同计算规则。

## 实际操作验收

1. 悬停模型 A 的 0.9、0.8 阈值点，核对阈值与指标；曲线采用库的阶梯表达。
2. 点击图例隐藏模型 B，确认 B 曲线及其基线一起隐藏、A 保持；恢复 B。两条基线重合，需结合实际系列可见状态核对，不能只凭线条外观。
3. 图例过滤不应重算 A 的样本数、正例率或 AP，也不应写回磁盘 request。
