# sensor-correlation

## 典型图型与场景

- 图型：`correlationMatrix`，多变量探索与相关方法切换。
- 覆盖：测量变量选择、逐对缺失、常量 NA、固定相关色域。

## 数据验收

- 输入 12 行；只有温度、压力、流量、参考电压进入 4×4 矩阵，数字设备编号不得进入矩阵。
- 温度–压力有效 N=10、相关 +1；温度–流量 N=10、相关 -1；压力–流量 N=8、相关 -1。允许数值误差 1e-10。
- 非常量变量的有效对角为 1；电压与所有变量的格子（包括自身）为 NA，不能用 0 或 1 代替。其有效配对 N 仍按各格实际数据核对。
- 所有方法在本输入的非退化单调关系上均为相应的 ±1；因此不能仅凭颜色没变判断方法未切换。

## 实际操作验收

1. 悬停温度–压力、压力–流量和电压–电压，核对系数/NA 原因与 N。
2. 切换 Spearman、Kendall，检查当前成功规范 Spec 的 method 已改变且图仍 rendered；恢复 Pearson。只改控件文字不算通过。
3. NA 显示与零相关色必须能区分，不自动填补缺失。

## 执行与公共验收

按[执行说明](../README.md#执行方式)只复制 [prompt.md](prompt.md) 和 [inputs/](inputs/) 给 Agent；本文件及 [fixtures.json](fixtures.json) 留在验收端。输入来源与 SHA-256 见校验清单。

同时检查[公共验收标准](../README.md#公共验收标准)。允许不同的配色和布局，不要求页面或像素一致。数据事实用于检查产物，不强制把所有计算写在页面上。
