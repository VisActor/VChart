# delivery-time-violin

## 典型图型与场景

- 图型：`violinPlot`，比较三种配送方案的分布形状。
- 覆盖：原始组内样本、自动带宽、密度与样本量的区分。

## 数据验收

- 共 120 条观测，标准/加急/经济配送分别为 48、48、24 条，全部有效，不能补齐或均衡组样本量。
- 三组原始范围分别为 36–47.1、18–32.2、44–56.8 小时。轮廓的 Gaussian 核尾可以超出原始极值，不能误写为观测范围。
- 使用 Gaussian/Scott、`densityNormalization=area`；不得手工伪造预计算 density、使用统一假带宽或改为 count/width 归一化。
- 图是各组密度轮廓，加急配送输入有两个数值带；是否画出多个可辨峰受带宽影响，不硬性要求固定峰数或像素形状。

## 实际操作验收

1. 分别悬停三组轮廓，核对组名、N、原始极值、有限正带宽和采样峰值密度。
2. 比较轮廓时不把峰值密度解释为概率或订单数。
3. 不应出现默认筛选或参数控件。
